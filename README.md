# empdata2k.com

Главная страница сайта в стиле пиратских iNFO/NFO-файлов 90-х: логотип `empdata2k`
псевдографикой, по буквам бегают и дерутся рыцари, над ними летает дракон и жжёт огнём.
Под футером секция `pROJECTS` со ссылками на другие проекты (сейчас
[pineapple](https://pineapple.empdata2k.com)).

Сайт статический, хостится на GitHub Pages (домен в `CNAME`). Весь сайт это один файл
`index.html` без внешних зависимостей: ни библиотек, ни шрифтов с CDN, ни картинок.

## Как это устроено

Страница эмулирует текстовый режим 80 колонок на `<canvas>`.

- **Сетка символов.** Ширина ячейки считается от ширины окна (максимум 1200px, минимум
  4px за ячейку), высота ячейки равна двум ширинам, как у шрифта 8x16. Экран центрируется
  в окне по обеим осям через `margin:auto` на `#wrap` (на телефоне в вертикальной раскладке
  экран сильно ниже окна); когда страница выше окна, авто-отступы схлопываются в ноль и
  ничего не обрезается.
- **Тайлы.** Каждый символ рисуется один раз в маленький offscreen-canvas и кэшируется по
  ключу `символ|цвет|фон`. Блоки `█▀▄▌▐`, штриховка `░▒▓` (дизеринг как в VGA) и рамки
  `─│┌┐└┘═║╔╗╚╝…` рисуются геометрически, поэтому выглядят одинаково в любом браузере.
  Буквы и прочие знаки рисуются через `fillText` моноширинным шрифтом.
- **Статический слой** (шапка, логотип, футер) рендерится один раз в отдельный canvas,
  на каждом кадре копируется целиком, поверх рисуются динамические объекты.
- **Палитра** CGA на 16 цветов (`PAL`). В строках статического экрана работают коды
  цвета: `§0`…`§f` цвет из палитры, `§#rrggbb` произвольный, `§-` вернуться к
  автоматической раскраске (заглавные белые, строчные серые, рамки тёмно-серые).
- **Логика** идёт с фиксированным шагом 20 тиков в секунду через `requestAnimationFrame`.

### Логотип

Логотип набран в стиле шрифта figlet «ANSI Shadow», но строчными буквами, которых в
этом шрифте нет. Глифы лежат в объекте `GLYPHS` в `index.html`: 10 строк на букву,
строки 0–6 верхние выносные (d, t, 2, k), 2–6 основная высота (e, m, a), 7–8 хвост p,
последняя строка каждой буквы это тень.

Глифы сгенерированы скриптом `tools/glyphs.js`: буква задаётся пиксельной маской из
`#` и `.`, тень (`╗║╝═╚╔`) достраивается алгоритмом, снятым с оригинального шрифта.
Скрипт содержит самопроверку на настоящих заглавных глифах ANSI Shadow. Чтобы изменить
или добавить букву: поправить маску в `LOWER`, запустить `node tools/glyphs.js`,
скопировать выведенный JSON в `GLYPHS`.

Ширина логотипа 72 колонки, высота 10 строк. Цвета: `LOGO_GRAD` (градиент по строкам,
от белого к серому) и `LOGO_SHADOW` (синяя тень).

### Рыцари

Маленькие спрайты 3x4 символа (`KN_R`, левая версия зеркалится автоматически):
голова `Θ`, щит `▐` цвета команды (красные и синие), корпус `█`, меч `─`, ноги `/ \`.

Верх букв логотипа служит рельефом (`SURF`): рыцарь идёт по контуру, перешагивает
ступеньки до двух строк, при обрыве разворачивается или спрыгивает, с земли запрыгивает
на буквы. Часть рыцарей решает пройти под буквами (`under`). Землёй снизу служит верхняя
полоса `▄▄▄` футера (`GROUND_ROW`).

Рыцари разных команд на одном уровне на расстоянии до трёх колонок начинают бой:
замах, укол, искра `*` при попадании, два очка здоровья. Убитый лежит `▄Θ▄─` и
исчезает, победитель поднимает меч. Новые заходят с краёв экрана, пока их меньше
`MAXK`.

Клик (или тап) в любом месте первого блока графики (от верхней рамки до нижней,
строки `0`…`BLOCK_BOT`) вызывает нового рыцаря. `freeSpot()` ищет ближайшее к точке
клика чёрное место, куда целиком влезает спрайт 3x4 (`roomFor()` проверяет по `SCREEN`,
что там нет ни букв, ни рамок); строки в расстоянии считаются вдвое, потому что ячейка
вдвое выше своей ширины. Команды чередуются (`popTeam` переключается на каждом вызове,
стартовый цвет выбирается монеткой), поэтому клики дают то красного, то синего. В точке спавна вспыхивает эффект (`spawnBurst()`)
того же цвета: кольцо `▓▒░`, которое расширяется шесть тиков, и веер искр `*+·`.
Рыцарь выпрыгивает вверх (`state:'jump'`) и дальше живёт как все остальные. Кликом можно набрать до `HARDK`
рыцарей, лимит `MAXK` касается только тех, что приходят с краёв сами.

### Дракон и огонь

Дракон это пиксель-арт 32x12 (`DRAGON_BASE` плюс три положения крыльев `WING_UP`,
`WING_MID`, `WING_DOWN`), который переводится в полублоки `▀▄█` с двумя цветами на
ячейку. Летает туда-сюда; проход бывает высокий (редкие пыхи) и низкий (жжёт над
логотипом сериями). Частицы огня `▓▒░` остывают от белого к красному, при попадании в
букву или землю оставляют «нагрев» (`heat`), который постепенно гаснет, попавшие под
огонь рыцари сгорают.

### Проекты

Секция под футером, отбитая от него тремя пустыми строками: заголовок
`──── ░▒▓█ pROJECTS █▓▒░ ────` и по одной записи на проект. Снизу секция отделена
от бегущей строки тонкой линией `─` во всю ширину и пустыми строками, отступы сверху
и снизу подобраны так, чтобы блок выглядел симметрично.

Запись занимает `PROJ_H` = 4 строки: слева пиксельная иконка 7x8 пикселей (рисуется
полублоками `▀▄█` тем же способом, что дракон), справа три строки текста по центру
иконки: имя, слоган, `» адрес`; у правого края серым две строки про проект
(`info`, `info2`).

Иконка ананаса собрана как обычный пиксель-арт: три листика, жёлтое тело со светлой
верхней полосой, глаза и рот. Раз в `BLINK_EVERY` тиков иконка моргает на
`BLINK_LEN` тиков: `applyProject()` держит в `p.wink` тот же рисунок с закрашенными
глазами, а `drawIcons()` рисует его поверх статического слоя. При наведении на запись
проект моргает ещё раз. Начальная фаза у каждого проекта своя (`p.blinkOff`), чтобы
иконки не моргали в такт.

Все проекты лежат в массиве `PROJECTS`:

```js
{ name:'pineapple', url:'https://pineapple.empdata2k.com/',
  tag:'sTAY aWAKE, lOOK aCTiVE', info:'wiNDOWS tRAY uTiLiTY', info2:'bUiLT oN .NET 10',
  icon:["...g...", ".d.g.d.", ...] }   // 8 строк по 7 символов
```

- `icon`: буквы это цвета из `PCOL` (`g` зелёный, `d` тёмно-зелёный, `y` светло-жёлтый,
  `n` жёлтый, `N` оранжевый для теневой стороны, `o` коричневый, `k` чёрный,
  `w` белый, `r` красный, `b` синий), точка прозрачная. Регистр буквы важен, поэтому
  новые оттенки можно добавлять в `PCOL` заглавными.
- `info`, `info2`: две серые строки у правого края. Номер версии тут не показывается
  специально, чтобы страницу не приходилось править после каждого релиза проекта.
- Иконка может быть любого размера, лишь бы её высота в строках (половина числа
  пиксельных строк) совпадала с `PROJ_H`, а ширина не доходила до `TEXT_COL`.
- Чтобы добавить проект: дописать объект в `PROJECTS`, нарисовать иконку и добавить
  строку-ссылку в блок `<noscript>`. Всё остальное (строки экрана, ссылка поверх canvas,
  фраза `cHECK oUT …` в бегущей строке) строится автоматически.

Ссылки настоящие: над каждой записью лежит прозрачный `<a class="proj">`, размер и
положение которого пересчитываются в `placeLinks()` при каждом `layout()`. Поэтому
работают клик, средняя кнопка, Tab и правое меню браузера. При наведении или фокусе
запись подсвечивается (`hot`): имя жёлтым, слоган белым, адрес ярко-голубым, маркер `»`
мигает; подсвеченный вариант строк хранится в `p.hot` и рисуется поверх статического
слоя в `drawProjects()`.

Раскладка: `ICON_COL` колонка иконки, `TEXT_COL` колонка текста, `PROJ_H` высота записи
(она же высота иконки в строках, то есть половина числа пиксельных строк).

## Отладка

Параметры в адресе страницы:

- `?t=300` прокрутить анимацию на 300 тиков вперёд сразу при загрузке.
- `?low` дракон всегда летает низко и жжёт.
- `?hot=0` подсветить запись проекта с индексом 0, как при наведении мыши.
- `?blink` держать глаза иконок закрытыми (чтобы поймать моргание на скриншоте).
- `?pop` кликнуть в трёх местах по буквам сразу при загрузке (вместе с `?t=` ловит
  эффект спавна на скриншоте).

Скриншот без запуска браузера (Windows, Edge):

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --hide-scrollbars --window-size=1240,1000 --screenshot=shot.png "file:///C:/_web/empdata2k/index.html?low&t=108"
```

Проверка синтаксиса скрипта:

```
sed -n '/<script>/,/<\/script>/p' index.html | sed '1d;$d' > page.js && node --check page.js
```

## Где что менять

| Что | Где в `index.html` |
|---|---|
| Тексты шапки и футера | массив `lines`, вызовы `three(...)` |
| Бегущая строка | константа `SCROLL` (фразы про проекты дописываются из `PROJECTS`) |
| Проекты, их иконки и ссылки | массив `PROJECTS`, палитра `PCOL`, блок `<noscript>` |
| Заголовок секции и отступы вокруг неё | вызов `rule('pROJECTS')` и `lines.push('')` рядом с ним |
| Годы | `1999-2026` в шапке, `sINCE 1999` в футере, текст в `SCROLL` |
| Раскладка по строкам | `LOGO_TOP`, `GROUND_ROW`, `ICON_COL`, `TEXT_COL` |
| Цвета | `PAL`, `LOGO_GRAD`, `LOGO_SHADOW`, `DCOL` (дракон) |
| Число рыцарей, гравитация | `MAXK`, `HARDK`, `G` |
| Спавн по клику и его эффект | `popKnight`, `freeSpot`, `spawnBurst`, `BLOCK_BOT` |
| Скорость и высоты дракона | `updateDragon`, `dragon.alt` |
| Заглушка без JavaScript | блок `<noscript>` |
